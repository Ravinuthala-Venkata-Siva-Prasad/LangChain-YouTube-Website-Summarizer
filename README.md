# 🦜 LangChain YouTube & Website Summarizer

An AI-powered application that summarizes content from YouTube videos and websites using LangChain, Groq, and Streamlit.

## 🚀 Features

- 🎥 Summarize YouTube video content.
- 🌐 Summarize website content using URLs.
- 🤖 Generate summaries using Large Language Models (LLMs).
- 🔗 Extract content using LangChain document loaders.
- ⚡ Interactive web interface built with Streamlit.
- 🔑 Secure API key input through the sidebar.
- 📝 Generate summaries of approximately 300 words.

## 🛠️ Technologies Used

- Python
- LangChain
- Groq
- Streamlit
- YouTube Loader
- Unstructured URL Loader
